# ReceptionAide: Public Site Repo

Code behind receptionaide.com, hosted on Jaron's Vercel (densolv-s-projects). Prospect demos deploy at receptionaide.com/{prospect}.

All business context, GHL configuration, credentials, the demo pipeline, and the staging playbook live in `../receptionaide/` (private). Do sales, demo, and ops work from that folder; this repo is site code only.

This is a PUBLIC repo: no credentials, tokens, prospect details, or client data get committed here, ever.
